Crown AI — amendment capture

The build environment cannot reach planning.vic.gov.au. Your browser can. This page turns a page you have opened into an evidence bundle the pipeline accepts, with the bytes kept so anything drawn from it can be rechecked.

It runs entirely in your browser. It makes no network requests — you can check that with the network tab, and it works with the machine offline.

1. Paste the page

Open the amendment page, press Ctrl/Cmd+U to view source, select all, and paste it here. Or save the page and paste the file's contents.

2. Check every field

The fields below are suggestions read from the page, and they may be wrong. Nothing is exported until you have checked each one against what you can see on the page. Anything you leave blank goes to the review queue instead of the graph.

3. Confirm and export

This becomes confirmed_by_operator in the bundle. The importer refuses a bundle without it, and your name is recorded against every record it creates.

4. Import it

python -m ingest.cli --capture crown-capture-....json --as you@crown.local
